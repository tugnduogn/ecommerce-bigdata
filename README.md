# Ecommerce Big Data Project

**Đề tài:** Phân tích hành vi khách hàng và Dự báo nhu cầu Thương mại điện tử  
**Dataset:** UCI Online Retail II  
**Công nghệ:** Hadoop, YARN, Spark, PySpark, Power BI

## Cấu trúc thư mục
- `data/`: Dữ liệu (không đẩy lên GitHub)
- `scripts/`: Code PySpark
- `hive/`: Script Hive
- `powerbi/`: Dữ liệu xuất cho Power BI
- `logs/`: Log chạy job
